# MiniQuiz Admin Panel (মিনি কুইজ অ্যাডমিন প্যানেল)

মিনি কুইজ (MiniQuiz) অ্যাপ্লিকেশনের প্রশ্নের ডেটাবেস পরিচালনার জন্য একটি আধুনিক ও স্বয়ংসম্পূর্ণ অ্যাডমিন প্যানেল। এই প্যানেলের মাধ্যমে সরাসরি সুপাবেস (Supabase) ডাটাবেসের `public.questions` টেবিলে প্রশ্ন তৈরি, সম্পাদনা, ড্রাফট এবং পাবলিশ করা যায়।

---

## 🌟 বৈশিষ্ট্যসমূহ (Features)

1. **সুপাবেস অথেন্টিকেশন (Supabase Auth)**:
   - সুরক্ষিত ইমেইল ও পাসওয়ার্ডের মাধ্যমে লগইন প্যানেল (`/login`)

2. **ড্যাশবোর্ড ডাইনামিক কাউন্টার (`/admin`)**:
   - মোট প্রশ্ন (Total Questions)
   - প্রকাশিত প্রশ্ন (Published Questions - status = `published`)
   - ড্রাফট প্রশ্ন (Draft Questions - status = `draft`)

3. **প্রশ্ন তালিকা ও অনুসন্ধান (`/admin/questions`)**:
   - `public.questions` টেবিল থেকে সব প্রশ্নের তালিকা প্রদর্শন
   - কলামসমূহ: `question`, `status`, `created_at`, `actions` (সম্পাদনা ও মুছে ফেলা)
   - রিয়েল-টাইম সার্চ এবং স্ট্যাটাস অনুযায়ী ফিল্টারিং

4. **নতুন প্রশ্ন যোগকরণ (`/admin/questions/create`)**:
   - প্রশ্ন (Question)
   - বিকল্প ক, বিকল্প খ, বিকল্প গ, বিকল্প ঘ (Options A, B, C, D)
   - সঠিক উত্তর নির্বাচন dropdown
   - সঠিক উত্তরের ব্যাখ্যা (Explanation)
   - স্ট্যাটাস: `published` অথবা `draft`
   - সেভ বাটন: **"প্রশ্ন সংরক্ষণ করুন"**

5. **প্রশ্ন সম্পাদনা ও মুছে ফেলা (`/admin/questions/edit/:id`)**:
   - বিদ্যমান প্রশ্নের তথ্য পরিবর্তন ও আপডেট
   - প্রশ্ন মুছে ফেলার পূর্বে নিশ্চিতকরণ ডায়ালগ

6. **স্টুডেন্ট অ্যাপ লাইভ প্রিভিউ (Live Student Sync)**:
   - স্টুডেন্ট অ্যাপে প্রশ্নগুলো কীভাবে প্রদর্শিত হবে তার সরাসরি প্রিভিউ দেখা যায়।

## 🗄️ Supabase Database Schema (`public.questions`)

আপনার সুপাবেস প্রকল্পে **SQL Editor** এ নিচের স্ক্রিপ্টটি রান করে `public.questions` টেবিলটি তৈরি অথবা নিশ্চিত করুন:

```sql
-- public.questions টেবিল তৈরি
CREATE TABLE IF NOT EXISTS public.questions (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  question TEXT NOT NULL,
  option_a TEXT NOT NULL,
  option_b TEXT NOT NULL,
  option_c TEXT NOT NULL,
  option_d TEXT NOT NULL,
  correct_answer TEXT NOT NULL,
  explanation TEXT,
  status TEXT NOT NULL DEFAULT 'published',
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Row Level Security (RLS) Enable করুন
ALTER TABLE public.questions ENABLE ROW LEVEL SECURITY;

-- Read Access for Everyone (Including Student App)
CREATE POLICY "Allow public read access for published questions"
ON public.questions FOR SELECT
USING (true);

-- Full Access for Authenticated Admins
CREATE POLICY "Allow admin full access"
ON public.questions FOR ALL
TO authenticated
USING (true)
WITH CHECK (true);
```

## 🔑 Environment Variables Setup

প্রকল্পের রুট ডিরেক্টরিতে `.env.local` অথবা `.env` ফাইল তৈরি করুন এবং আপনার Supabase প্রকল্পের ক্রেডেনশিয়াল যোগ করুন:

```env
# Supabase Credentials
NEXT_PUBLIC_SUPABASE_URL="https://your-project-ref.supabase.co"
NEXT_PUBLIC_SUPABASE_ANON_KEY="your-supabase-anon-key"

# Vite compatibility
VITE_SUPABASE_URL="https://your-project-ref.supabase.co"
VITE_SUPABASE_ANON_KEY="your-supabase-anon-key"
```

## ☁️ Vercel Deployment (ভার্সেল ডিপ্লয়মেন্ট নির্দেশিকা)

এই প্রজেক্টটি Vercel-এ ডিপ্লয় করার জন্য প্রস্তুত।

১. আপনার প্রজেক্টটি GitHub-এ পুশ করুন।
২. [Vercel Dashboard](https://vercel.com)-এ যান এবং **"Add New Project"** সিলেক্ট করুন।
৩. GitHub রিপোজিটরিটি সিলেক্ট করুন।
৪. **Environment Variables** সেকশনে যুক্ত করুন:
   - `NEXT_PUBLIC_SUPABASE_URL` = `https://your-supabase-url.supabase.co`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = `your-anon-key`
   - `VITE_SUPABASE_URL` = `https://your-supabase-url.supabase.co`
   - `VITE_SUPABASE_ANON_KEY` = `your-anon-key`
৫. **Deploy** বাটনে ক্লিক করুন।

বিল্ড কমান্ড:
`npm run build`

## 🔄 ডাটাফ্লো (Database Flow)

```
অ্যাডমিন প্যানেল (Admin Panel)
       ↓
Supabase public.questions (status = 'published')
       ↓
স্টুডেন্ট অ্যাপ (Student App)
```

অ্যাডমিন প্যানেলে যেকোনো প্রশ্ন `status = published` দিয়ে সেভ করলেই তা স্বয়ংক্রিয়ভাবে স্টুডেন্ট অ্যাপে যুক্ত হয়ে যাবে!
